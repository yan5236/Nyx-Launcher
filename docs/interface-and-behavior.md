# 界面与功能

## 当前能力

| 入口 | 已实现 | 边界 |
| --- | --- | --- |
| 首页 | 选择本地版本、账户启动、阶段反馈、停止与故障日志 | 发现窗口不代表世界已加载完成 |
| 版本管理 | 目录登记、扫描、搜索、改名、图标、回收站删除、整合包导入、模组管理 | 导出 Tab 仍为空 |
| 下载 → 游戏 | 原版及 Fabric / Forge / NeoForge 安装、可选 Fabric API | 不提供 Quilt 安装 |
| 下载 → 模组 | 搜索、三级详情、必需前置跳转、安装或指定目录下载 | 不自动解析、安装或升级整套依赖 |
| 下载 → 资源包 / 数据包 / 光影 | 选择兼容发布、安装到版本或存档、指定目录下载 | 不自动启用，不安装光影加载器 |
| 下载 → 整合包 | 在线安装及本地 Modrinth / MCBBS / MultiMC 导入 | 具体限制见[整合包安装](modpack-installation.md) |
| 本地拖入 | 识别 JAR / ZIP / MRPACK 并确认安装目标 | 不完整解析本地资源游戏版本范围及依赖 |
| 账户与设置 | 离线、微软、外置账户；隔离、内存、高级启动、Java、下载偏好 | 微软入口需要有效的构建配置 |

资源目录当前查询 Modrinth，CurseForge 搜索不可用。“全部来源”不代表已接入多个平台。下载任务不支持跨重启恢复。

## 页面交互

侧栏提供首页、版本管理、下载及底部账户入口；账户菜单进入账户和设置。沿用浅色原生控件、现有绿色主操作和红色停止语义，不增加重复标题与描述性副标题。转场遵循系统动画开关，离开页面时取消加载并丢弃迟到结果。

游戏搜索过滤已加载清单；其他资源通过搜索按钮或 Enter 提交，筛选改变回到第一页。资源详情返回保留目录的搜索、筛选、页码与滚动位置。版本筛选可手动输入，平台标签与卡片摘要不作为安装兼容性的唯一依据。详见[模组与资源](mod-downloads.md)。

## 版本与目录

启动器在 EXE 所在目录创建默认 `.minecraft`；目录登记和各目录所选版本保存在用户配置中。移除目录登记不删除磁盘文件，已移除的默认目录不会被强行重新登记。扫描读取本地版本与继承关系，坏清单保留错误提示；列表出现版本不代表完整性检查通过。

版本详情提供基础、模组管理、游戏设置、导出四个 Tab。基础页可同步改名目录、同名清单/JAR 与标识，保存自定义图标，并打开版本、模组、存档和截图目录。非法名称、冲突、链接、坏清单及被其他版本依赖的基础版本会拒绝改名。删除需确认并将单个版本目录移入回收站，其中独立存档和模组也会移走，不删除共享资源。游戏启动/运行及相关安装任务执行、收尾期间阻止改名和删除。

隔离可关闭，或按模组版本、非正式版、两者、所有版本选择。隔离时以版本目录作为游戏目录，否则使用游戏根目录；assets、libraries、runtime 共享。整合包始终使用自己的实例目录。切换隔离策略不迁移已有存档、模组或设置。

### 模组管理

每张卡片左侧提供多选框；勾选后在搜索框下方一行的左侧显示批量更新、启用、禁用和删除图标及“全选”，同一行右侧依次是状态筛选、从文件安装和下载模组。全选仅作用于当前筛选结果，隐藏的项目自动取消勾选。批量更新只处理有更新的所选项目，悬停列出对应目标版本；启停跳过已处于目标状态的文件。批量删除统一确认后移入回收站，单项失败继续其余文件并汇总错误。

模组管理读取实际游戏目录直属的 `.jar` 和 `.jar.disabled`，支持按模组名或文件名搜索、全部/已启用/已禁用筛选。通过 SHA-1 批量匹配 Modrinth，仅将项目名称、简介和图标用于卡片；未知文件以文件名显示，网络失败仍可管理本地文件。卡片不显示统计、版本标签或说明副标题，详情、启停、位置、删除均使用带悬停提示和无障碍名称的图标。

加载摘要后检查与当前 Minecraft 版本和加载器匹配的较新正式发布；没有更新或尚未确认更新时隐藏更新图标，有更新时悬停显示目标版本号。更新先下载、校验，再复核旧文件和游戏运行状态后替换，保持原启停状态；失败或同名冲突保留旧文件。仅更新所选模组，不自动升级或安装依赖。离开分类会取消在途更新；更新在当前页显示进度，不进入下载任务页。

启停通过增删 `.disabled` 后缀实现，禁用模组名称显示删除线，名称与图标同时淡化，图标中央显示横线；启用后恢复正常；单项与批量启停仅更新变化的卡片，保留已有摘要、选择和滚动位置，不重新扫描或发起网络请求。加载中的摘要与更新结果合并时保留已修改的启停状态；不再符合当前筛选的卡片会移出列表。删除确认后移入回收站；文件位置打开资源管理器并选中文件。“从文件安装”使用原生 JAR 选择器，验证归档和加载器后复制到当前版本，不覆盖不同内容的同名文件；本地游戏版本范围与依赖仍需用户核对。“下载模组”直接进入下载页的模组分类。游戏运行或安装中拒绝修改；未隔离时这些操作影响共用同一 mods 目录的版本。

已被 Modrinth 识别的模组详情弹窗提供“Modrinth 主页”和“下载”：前者用系统浏览器打开项目主页，后者携带当前 Minecraft 版本及加载器，直接进入对应项目下载详情的文件列表，无匹配文件时显示空列表，不替换为其他版本或加载器。未识别文件不显示这两个入口。

## 下载与安装任务

游戏、模组、资源及 Java 安装复用独立下载任务页。创建任务后可离开页面；支持进度、暂停/继续、失败重试和取消。完成或取消清理结束后删除的是任务记录，不删除已发布文件或共享资源。

任务捕获创建时的目录与配置，传输共用并发、连接和速率预算，活跃批次沿用原限制。版本列表源与文件源分别设置，支持镜像优先、官方缓慢回退和官方优先。游戏使用 BMCLAPI，Modrinth 资源使用 MCIM，自定义链接不改写，认证不走镜像。

文件先写临时文件，校验后发布，同名冲突不静默覆盖。游戏和整合包完成暂存区安装后发布新版本，同一游戏目录的安装任务保护共享处理器输出。暂停复用已完成且有效的文件，未完成的单文件可能重新下载；取消不删除已成功下载的共享资源。关闭应用拒绝新任务并等待在途任务清理。

公共下载跨批次复用连接池，同时保留批次取消与预算。连接复用减少反复建连，但不能保证消除系统或代理端口耗尽。参数由 [DownloadHttpClient](../src/NyxLauncher/Services/DownloadHttpClient.cs) 维护。

## 内存与高级启动

全局设置 → 启动和版本详情 → 游戏设置共用内存与高级卡片。版本默认继承全局，修改后保存完整局部偏好，后续全局修改不覆盖它；游戏设置顶部独占一行、靠右的“恢复全局设置”按钮同时清除内存和高级启动的版本覆盖，之后持续跟随全局，直到再次手动修改版本设置。配置损坏或写入失败保留原值。

内存支持自动估算和手动分配。估算考虑游戏版本、加载器、实际模组目录及实时内存，公式由 [MemorySettings](../src/NyxLauncher/Services/MemorySettings.cs) 维护。界面预览不替代启动时计算，手动值不会因空闲内存下降而自动缩小，JVM 堆外仍会占用额外内存。

高级设置支持 JVM/游戏参数、GC、兼容组件开关与高性能 GPU 偏好。参数格式或 GC 冲突会报错，用户参数可能改变内存行为或导致启动失败。GPU 偏好写入当前用户针对实际 Java 路径的 Windows 设置，不保证硬件最终选择。组件条件与许可见[启动组件](launch-components.md)。

全局内存和高级配置分别为用户数据目录中的 `launch-memory.json`、`launch-advanced.json`；版本覆盖为版本目录中的 `nyx-memory.json`、`nyx-launch.json`，随版本改名和删除，不随隔离策略迁移。Java 规则见[Java 管理](java-management.md)，账户与日志规则见[账户与启动](accounts-and-launch.md)。
