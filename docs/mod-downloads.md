# 模组与资源安装

下载 → 模组 → 点击卡片，以淡入淡出进入详情，返回时保留搜索、筛选、页码及滚动位置。顶部展示真实模组图标、名称和简介，支持复制名称及使用默认浏览器打开 Modrinth 项目详情。

依次选择 Minecraft 版本、加载器、模组文件，阶段栏显示当前进度和已选内容，左侧按钮撤回上一步。游戏版本与阶段栏复用现有 `java-mojang.png` 草方块，加载器复用品牌图标。每一级使用可滚动的按钮卡片，不截断文件列表；游戏版本和加载器卡片仅显示名称及图标，不显示副标题。文件以文件名为主标题，副标题为本地日期和中文发布渠道，正式版显示绿色 R，测试版橙色 B，预览版红色 A。

目录中已提交的 Minecraft 版本和加载器筛选会传入详情：对应选项存在时置顶，并在标题同行标注“筛选版本”或“筛选加载器”；其他选项仍可选择，不补造当前项目不支持的筛选项，也不自动跳过三级选择。

选到模组文件阶段后，在列表顶部显示“前置资源”，按当前 Minecraft 版本和加载器匹配的文件合并、去重平台声明的必需依赖，并检查前置项目自身是否有同一版本与加载器组合的运行文件；无匹配发布的前置不显示，避免多加载器发布把 Fabric API 带到 NeoForge 等列表。卡片包含真实图标、模组名和简介，底部分隔线与文件共同滚动；无必需前置时隐藏整个区域。前置请求失败可单独重试，仍可选择文件下载。点击前置卡片后继承当前 Minecraft 版本和加载器，直接进入对应项目的文件列表；若组合无兼容文件则显示空列表，可撤回调整。左上角返回按跳转历史恢复来源项目的文件列表、选择及滚动位置，安装完成后也保持此规则；最外层才返回下载目录。支持逐层返回，目录原有搜索、筛选和页码保留。

## 真实数据与安装

- 使用 [Modrinth 项目全部版本接口](https://docs.modrinth.com/api/operations/getprojectversions/)，省略更新日志；基于真实文件的兼容范围生成游戏版本及加载器选项，而非搜索卡片摘要。保留该发布所有运行 JAR，主文件优先，排除源码、开发、签名等附件和非 JAR 文件。
- 依赖仅取 `required`，排除可选、冲突及已内嵌项目；仅有 `version_id` 的依赖先批量补全所属项目，再用 [批量项目接口](https://docs.modrinth.com/api/operations/getprojects) 读取卡片。只有外部文件名、无平台项目或版本编号的依赖无法跳转，不列入卡片。请求沿用现有超时、响应上限、取消和官方图标地址校验。
- 复用目录请求的 20 秒超时、8 MiB 响应限制、系统代理、TLS 校验及中文失败重试；超限明确报错，不显示不完整列表。离开页面取消清单请求并关闭弹窗。
- 点击文件弹出“选择安装版本”，仅列当前游戏目录内 Minecraft 版本和加载器类型均精确匹配、清单有效的已安装版本；显示目标 `mods` 路径。无兼容版本或未选游戏目录时，仍可使用“选择文件夹下载”调用系统目录选择器，直接将文件保存到所选目录（不追加 `mods`），并创建统一下载任务；取消选择不创建任务，失败留在弹窗显示原因。手动目录不校验本地游戏兼容性，仍保留文件哈希、同名保护和目录检查。
- 点击目标卡片即调用现有 `DownloadTaskManager.AddMod`，下载出现在统一“下载任务”中。共用 `DownloadTransport` 的连接预算、并行、限速、分段、暂停/继续、重试、取消及临时文件清理。离开详情不停止已创建任务。
- 创建任务时固定目标目录及隔离设置，开始及重试时重新扫描校验版本。启用隔离时写入 `versions/<版本名>/mods`，关闭隔离时写入游戏根目录 `mods`，与实际启动规则一致；不因下载模组修改全局设置。
- 文件要求有效的项目官方 CDN HTTPS 地址、单级 JAR 文件名、非负大小与 SHA-1。兼容官方历史链接的 `//data/` 路径及大小为 0 的记录；0 表示平台未提供有效大小，仍使用传输响应长度和 SHA-1 验证内容，不视为空文件。完整同名文件复用；同名不同内容拒绝覆盖。下载校验后原子发布，失败或取消清理未完成文件，不删除已安装模组。

当前只安装所选文件，前置卡片提供手动跳转和安装，不自动解决依赖、升级或移走旧版本，安装前应自行处理同一模组不同文件名的旧版本。前置区域是当前兼容文件的必需项目合集，不表示每个历史文件都要求同一组依赖；跳转按 Minecraft 版本和加载器筛选，不锁定某个依赖版本。兼容筛选不解析 JAR 内的最低 Loader 版本或其他依赖约束。Quilt、LiteLoader、Rift 的发布可浏览，但当前版本扫描器和游戏安装器主要支持 Fabric / Forge / NeoForge，因此这些其他加载器可能没有可选本地目标。资源包、光影包和数据包的下载流程见下文。

模组下载正在排队、传输、暂停收尾或取消清理时，与游戏安装共用版本目录保护，禁止改名和删除版本。暂停完成后可修改目录；任务恢复时仍重新校验原目标，已改名或删除的目标不会被重新创建。

整合包复用三级详情，但通过名称弹窗创建新实例，见[整合包安装](modpack-installation.md)。

## 资源包、光影包与数据包

三类资源复用同一详情页，依次选择 Minecraft 版本、ZIP 文件，无加载器选择步骤。仍使用真实发布日期、渠道、筛选版本置顶，以及统一下载任务的暂停、重试、取消、SHA-1 校验和同名保护。

- 资源包和光影包选择当前游戏目录内游戏版本匹配的客户端，分别下载到实际运行目录的 `resourcepacks` 和 `shaderpacks`；实际运行目录沿用版本隔离和整合包强制隔离规则。
- 数据包选定文件后，弹窗分为“选择安装版本”和“选择存档”两步，通过标题左上角箭头返回上一步。存档卡片显示目录名称、通过文件流实际读取的该存档 `icon.png` 和目标路径；没有图标或解码失败时使用草方块。仅列实际运行目录 `saves` 中含 `level.dat` 的直属存档，文件写入所选存档的 `datapacks`。
- 三类资源均可选择文件夹直接下载，不追加任何子目录，也不要求本地存在客户端。数据包的两个步骤均保留此入口。
- 创建、开始和重试客户端安装任务时重新验证版本与存档归属；拒绝链接路径、已删除存档及不兼容版本，不会自动创建存档。活跃任务沿用版本目录保护。
- 只下载所选 ZIP，不自动启用资源包、光影或数据包，不安装光影加载器，也不解压、修改存档内容。客户端按 Minecraft 版本匹配，不验证额外渲染器要求。

## 本地拖入安装

将 ZIP、JAR 或 MRPACK 文件拖入启动器可安装本地资源；多文件按拖入列表逐个确认。根据归档内部标记识别资源包、数据包、光影、Fabric / Quilt / Forge / NeoForge 模组以及已有的 Modrinth / MCBBS / MultiMC 整合包。整合包继续走原安装流程；其他资源直接复用下载使用的 `ModInstallDialog`，本地入口按钮为“选择文件夹安装”。不识别的文件、文件夹或类型混合的包会明确报错，不猜测安装目录。

下载与本地安装均将当前游戏目录所选的版本放在候选首位；不在候选中的版本不会被额外加入。其余版本维持原顺序。数据包继续先选版本再选存档，返回版本列表保留排序。

本地资源按现有隔离规则进入 `resourcepacks`、`shaderpacks`、`mods` 或所选存档的 `datapacks`。也可选择文件夹原样复制。源文件保留，不解压、不自动启用，不安装前置依赖。相同内容的同名文件复用，不同内容拒绝覆盖；通过临时文件完成复制后再发布，失败保留弹窗和错误信息。复制期间禁止重复操作及关闭弹窗。

本地模组只按归档声明的加载器筛选；尚不解析游戏版本范围、最低加载器版本和前置依赖。资源包、数据包及光影亦不验证游戏格式版本，安装前需自行核对兼容性。

## MCIM 镜像源

按 [MCIM 接入指南](https://www.mcimirror.top/guide/start/getting-started) 复用现有设置，不新增源选项：搜索、标签、项目/前置和发布列表使用“版本列表源”；图标、模组、资源包、数据包、光影、整合包及其文件和 Fabric API JAR 使用“文件下载源”。镜像优先失败回退官方，官方优先失败回退镜像；官方缓慢策略在元数据/图标三秒后并发镜像，在文件响应头超过三秒后切换镜像。下载批次仍锁定原文件策略，资源请求读取最新设置。

- `api.modrinth.com` → `mod.mcimirror.top/modrinth`；`cdn.modrinth.com` → `mod.mcimirror.top`。
- 整合包中的 `edge.forgecdn.net` 文件可走 MCIM，`mediafilez.forgecdn.net` 按文档保持原样。CurseForge 搜索入口仍未启用。
- 统一 UA 为报备的 `Nyx-Launcher/{程序集版本号}`，覆盖 API、图标每次重定向、文件 HEAD/GET/Range。名称固定，版本随程序集发布版本更新。
- 图标跟随最多五次 HTTPS 重定向，每源保留 4 MiB、尺寸与解码限制。文件仍校验长度和 SHA-1，保留禁止覆盖、取消和原子发布规则。自定义下载链接不会改写。
- MCIM 返回缓存，可能晚于官方；当前按所选源接受有效缓存，不把 `sync_at` 当作发布时间，也不自动判定“最新版本”。需要刚发布的版本时选官方优先。镜像 404/连接失败回退官方，双源失败继续显示错误。
