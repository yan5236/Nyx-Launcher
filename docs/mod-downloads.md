# 模组下载

下载 → 模组 → 点击卡片，以淡入淡出进入详情，返回时保留搜索、筛选、页码及滚动位置。顶部展示真实模组图标、名称和简介，支持复制名称及使用默认浏览器打开 Modrinth 项目详情。

依次选择 Minecraft 版本、加载器、模组文件，阶段栏显示当前进度和已选内容，左侧按钮撤回上一步。游戏版本与阶段栏复用现有 `java-mojang.png` 草方块，加载器复用品牌图标。每一级使用可滚动的按钮卡片，不截断文件列表；游戏版本和加载器卡片仅显示名称及图标，不显示副标题。文件以文件名为主标题，副标题为本地日期和中文发布渠道，正式版显示绿色 R，测试版橙色 B，预览版红色 A。

## 真实数据与安装

- 使用 [Modrinth 项目全部版本接口](https://docs.modrinth.com/api/operations/getprojectversions/)，省略更新日志；基于真实文件的兼容范围生成游戏版本及加载器选项，而非搜索卡片摘要。保留该发布所有运行 JAR，主文件优先，排除源码、开发、签名等附件和非 JAR 文件。
- 复用目录请求的 20 秒超时、8 MiB 响应限制、系统代理、TLS 校验及中文失败重试；超限明确报错，不显示不完整列表。离开页面取消清单请求并关闭弹窗。
- 点击文件弹出“选择安装版本”，仅列当前游戏目录内 Minecraft 版本和加载器类型均精确匹配、清单有效的已安装版本；显示目标 `mods` 路径。无兼容版本时提示先安装对应游戏和加载器。
- 点击目标卡片即调用现有 `DownloadTaskManager.AddMod`，下载出现在统一“下载任务”中。共用 `DownloadTransport` 的连接预算、并行、限速、分段、暂停/继续、重试、取消及临时文件清理。离开详情不停止已创建任务。
- 创建任务时固定目标目录及隔离设置，开始及重试时重新扫描校验版本。启用隔离时写入 `versions/<版本名>/mods`，关闭隔离时写入游戏根目录 `mods`，与实际启动规则一致；不因下载模组修改全局设置。
- 文件要求有效的项目官方 CDN HTTPS 地址、单级 JAR 文件名、非负大小与 SHA-1。兼容官方历史链接的 `//data/` 路径及大小为 0 的记录；0 表示平台未提供有效大小，仍使用传输响应长度和 SHA-1 验证内容，不视为空文件。完整同名文件复用；同名不同内容拒绝覆盖。下载校验后原子发布，失败或取消清理未完成文件，不删除已安装模组。

当前只安装所选文件，不自动解决依赖、升级或移走旧版本，安装前应自行处理同一模组不同文件名的旧版本。兼容筛选不解析 JAR 内的最低 Loader 版本或其他依赖约束。Quilt、LiteLoader、Rift 的发布可浏览，但当前版本扫描器和游戏安装器主要支持 Fabric / Forge / NeoForge，因此这些其他加载器可能没有可选本地目标。不改变其余资源类别的浏览行为。
