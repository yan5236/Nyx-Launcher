# Java 管理与安装

从左下角账户菜单打开“设置 → Java”。右上角提供“导入 Java”“扫描 Java”和深色“安装 Java”。列表上方显示 Java 8、17、21、25 是否已有可用的 x64 安装。

## 本地列表

全新配置首次进入 Java Tab 时，自动在后台浅扫描所有就绪盘符，每个搜索起点最多向下三层；同时检查已登记目录、环境变量和常见 Java 安装位置，深层自定义目录可手动导入。开始前持久化首次扫描标记，之后切换页面或重启均不再自动扫描；停止或失败后也由用户手动重扫。已有旧配置升级后视为已初始化，不重复自动扫描。扫描期间按钮变为“停止扫描”。扫描只读取 `bin/java.exe` 的 PE 架构、`release` 或文件版本资源，不执行发现的程序。权限不足、不可访问目录和目录联接会跳过；启动器自己的未发布安装暂存区不加入列表。扫描完成后合并、去重并保存，取消不会提交半份结果，也不显示停止提示条。无法读取版本元数据的非标准 Java 不会被当作有效安装。

可以通过系统文件夹选择器导入 Java 根目录或 `bin` 目录。卡片显示主版本、完整版本、架构、厂商和路径，并支持打开文件夹。移除只删除登记，**不会删除或卸载 Java**；重新扫描会再次发现。移除当前选择会切回“自动选择”。列表与选择保存至 `%LOCALAPPDATA%/NyxLauncher/java-settings.json`，与下载偏好独立。配置读取失败时保留原文件，自动扫描不会启动，手动扫描、导入、安装登记及选择变更也不会覆盖它；需修复配置并重启后再保存。

设置分类、操作按钮与版本检查保持固定，“自动选择”与下方本地 Java 卡片在同一列表内同步滚动。切换选择只原位更新单选圆圈，保留卡片与滚动位置，不重播列表入场动画；扫描、导入、安装或移除实际改变列表内容时才重新绑定。列表卡片右侧预留滚动条间距，滚动条不覆盖顶部操作或卡片内容。

## 安装向导与下载任务

1. 点击 Java 8、17、21 或 25 的按钮卡片后，直接进入渠道选择，无需再点“下一步”；外观与渠道按钮一致，不预选或保留选中高亮，Tab 聚焦后可用 Enter 或空格激活。
2. 选择 Mojang、Eclipse Temurin 或 Zulu。卡片左侧使用本地图标。
3. 从当前渠道的真实可用版本列表选择具体发行包。按版本数字降序排列，默认选中第一项，支持选择旧版本。没有版本或网络失败时可返回或重试。

第二、三步左上角可返回；全程可用右上角叉、取消或 Esc 关闭。前两步直接点选卡片前进，底部仅保留取消；第三步在右侧显示深色“安装 Java”，选中具体发行包后才能提交。返回主版本页后，可再次点击同一版本继续。弹窗开关采用原生 WinUI 动画，步骤切换沿用登录弹窗的 220ms 淡入平移，并遵循系统动画开关。关闭或返回会取消版本加载，迟到结果不改变当前步骤。

点击最终“安装 Java”创建现有“下载 → 下载任务”中的标准任务，复用任务卡片、Badge、进度、暂停/继续、取消、失败重试和下载预算。创建成功后关闭向导，不再显示底部任务入口提示；失败仍显示错误。关闭向导、切换页面不会停止任务。任务记录仍遵循现有的会话级生命周期，不提供跨重启续传。

Java 固定安装到 **启动器 EXE 所在目录的 `Java/<发行包标识>`**，不修改系统 PATH 或注册表。包先下载至 `Java/.staging/<任务 ID>`，完成完整性校验、解压和实际主版本/x64 检查后发布，随后自动加入 Java 列表，保留原选择。取消不发布半成品；暂停复用已验证的 Mojang 文件或完整 ZIP，未完成的单文件重新下载。移除下载记录不删除已安装的 Java。已有安装目标不会被覆盖，可通过扫描或导入重新登记。

- **Mojang**：读取官方 Windows x64 运行时清单，提供游戏运行时（不承诺完整 JDK），校验清单及每个文件的 SHA-1；实际文件仍可使用现有 Mojang/BMCLAPI 源策略。
- **Temurin**：读取 Adoptium 正式版 API、Windows x64 HotSpot JDK ZIP，分页加载可用版本并校验 SHA-256。
- **Zulu**：读取 Azul Metadata API 的正式免费 Windows x64 JDK ZIP，选定包后获取详情及 SHA-256；元数据 `size` 为取整值，只作为估算，传输完整性依据 HTTP 实际长度与 SHA-256。

ZIP 和远程文件清单拒绝路径穿越、Windows 保留名称、备用数据流和链接。ZIP 展开内容上限为 4 GiB；安装和清理均检查路径范围，不覆盖用户现有 Java。安装目录不可写或登记失败会作为任务失败明确显示。

## 启动选择

默认“自动选择”从登记列表、当前游戏目录的 `runtime` 和启动器 `Java` 目录选择 **与游戏要求相同主版本中最新的 x64 Java**。启动时重新读取实际版本，忽略失效路径。游戏要求来自本地清单的有效 `javaVersion`，支持加载器继承，未声明的老版本默认 Java 8；因此 Java 25 不会被当作 Java 8/17/21 的无条件替代品。Java 16 等其他主版本可从本地扫描或导入获得。

点击 Java 卡片可手动固定选择，卡片左侧使用与“自动选择”相同的单选圆圈，二者互斥，重启后恢复已保存的选择。手动路径不存在、主版本不匹配或非 x64 时明确提示，不会悄悄切换另一套 Java。一次启动固定配置快照和最终路径，准备依赖与创建进程使用同一路径；期间改变列表或选择只影响下一次启动。缺失所需 Java 时提示到设置扫描、导入或安装。

.\.dotnet\dotnet.exe run --project tests/NyxLauncher.Checks -- --java-catalog .local/java-qa
