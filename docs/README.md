## 共同维护约定

- 行为、配置或接口变更时，同步对应主题文档；一个主题只维护一份完整说明，其他文档链接到它。
- 记录用户可观察的行为、边界、失败处理和设计原因。引用源码文件，不复制函数实现、配置全文、完整常量表或算法。必要的操作命令集中在开发与验证指南。
- SDK、依赖版本、配置结构和固定数据以项目文件、配置示例及对应源码为准，避免多处手工同步。
- 不将个人绝对路径、代理端口、账号、本机 SDK/缓存布置、临时脚本、截图路径和逐次验收流水写入共享文档。可复用的方法留在仓库，本机证据放在 Git 忽略的本地目录。
- 通用产品数据位置可以记录，例如用户配置目录、游戏目录和暂存目录；这些属于协作所需的行为约定。
- 验证报告区分已运行、失败及未验证范围，放在对应提交或评审中；一次本机成功不是长期兼容性承诺。

仓库的 `.local/` 已由 [.gitignore](../.gitignore) 排除，可存放本地笔记和验收产物；不要从共享文档链接这些文件，也不要强制提交。整理前文档已在该目录下归档。历史提交不会因本次整理被改写。
